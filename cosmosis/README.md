# Cosmosis DES-Y6 Model Vectors

This folder contains model vectors and additional data generated by Cosmosis for two fiducial cosmologies: one for LCDM and another for w0waCDM. The data is stored in `lcdm_datavector_run/` and `w0wacdm_datavector_run/`. The real-space 2pcfs are in the `shear_xi_plus/`, `shear_xi_minus/`, `galaxy_xi/`, and `galaxy_shear_xi/` folders. The folders contain additional information from the pipeline, such as n(z), C_\ell, distances, IA power spectra, etc. Any questions, please contact João Rebouças.

## Fiducial Parameters

- h: 0.67
- Omega_m: 0.319 
- Omega_b: 0.049
- As: 2.1e-9
- ns: 0.96
- Neff = 3.044, num_massive_neutrinos = 3, mnu = 0.06 eV
- (derived) sigma8 = 0.81527, S8 = 0.84069
- Nonlinear P(k) and baryonic feedback: HMCode2020 with log(T_AGN) = 7.7

- w0: -0.8 (only for w0waCDM)
- wa: -0.6 (only for w0waCDM)

Choices for nuisance parameters are:
- U_source: 0
- U_lens:   0
- M: -0.00339767, 0.0064552, 0.01593935, 0.00169811
- IA: NLA, A1 = 1.0, eta1 = -1.0, zpiv = 0.3
- Linear galaxy bias: 1.54, 1.81, 1.85, 1.76, 1.93, 1.9
- Lens Magnification alphas: 1.58, 1.38, 2.04, 2.21, 2.45, 2.42

## Running Cosmosis

After installing cosmosis and setting up the environment, do
```
    cosmosis ini/lcdm/params.ini
```

The user may need to adjust paths in the ini file to match their filesystem. João is running this in NERSC.
